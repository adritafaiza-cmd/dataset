## 1. What “clean” means

A candidate is **clean** only if both gates pass:

1. **Functional:** Xcelium testbench prints `ALL TESTS PASSED`.
2. **CDC/RDC:** JasperGold report has **0 errors and 0 warnings** in CDC
   and RDC sections.

`cdc_explicit` is a **prompt paragraph only**. It does not change the
testbench or the Jasper Tcl.

Jasper is started **only after** a functional pass
(`scripts/eval_all_generated.py`, `scripts/evaluate_pass_at_n.py`).
`cdc_errors: null` means Jasper never ran, not that CDC is clean.

**Nothing LLM-generated is clean.** The only clean RTL is golden
`benchmarks/*/fixed/rtl`.

## 3. How the golden tests were obtained

They were **not** generated by an LLM.

1. Collect open-source CDC blocks (PULP, ZipCPU, dpretet, verilog-axis, and others).
2. Store each as `benchmarks/<name>/` with `original/rtl` (upstream) and
   `fixed/rtl` (our CDC/RDC repairs: reset sync, Gray pointers, 2-flop, common reset).
3. Write or adapt a functional testbench (`tb/`) and `sim/run.sh`.
4. Write `jasper/run.tcl` plus SDC. Declare clocks, async resets, which ports
   belong to which clock.
5. Iterate until `fixed/rtl` gets `ALL TESTS PASSED` and Jasper 0/0.

Provenance (pilot): baseline `0d63dfb`, fixed RTL `a609317`, layout `bf3672c`.

Families:

- **dpretet:** `async_fifo`, `async_bidir_fifo`, `async_bidir_ramif_fifo`
- **ZipCPU:** `wbxclk`, `axixclk`, `apbxclk`
- **verilog_axis:** `axis_async_fifo`, `axis_async_fifo_adapter`
- **pulp_platform:** `cdc_2phase`, `cdc_4phase`, `cdc_2phase_clearable`
- plus 33 catalog circuits (`imported_unverified` in manifests)

`run_all_sim.sh` loops `benchmarks/*/sim/run.sh`, which hardcodes
`fixed/rtl`. That is why the Torch extract “came clean”: we re-scored the
answer key.

## 4. How prompts are written

All live prompts: `experiments/prompts/` (44 circuits x 2 = 88 files).

**Shared rules (both prompt types):**

- Role: professional Verilog designer.
- Module name, language, clocks (async, no phase relationship), resets,
  every port, parameters, behavior bullets.
- End with a port skeleton.
- **Forbidden:** testbench, markdown, vendor primitives, **reference RTL**,
  Gray-code recipes, “use N flop stages,” pointer diagrams.

**`*.functional.md` (Prompt A)**
Ports plus functional behavior only. Example (`cdc_2phase`): accept on
`src_valid_i && src_ready_o`; deliver once, in order; hold `dst_valid_o` /
`dst_data_o` while not ready; idle after reset; no spurious dest beat.

**`*.cdc_explicit.md` (Prompt B)**
Identical, plus this paragraph (no architecture names):

> The implementation must be safe for clock-domain and reset-domain
> crossings and must pass structural CDC/RDC analysis with zero unsafe
> crossings. Reset release must be safe in each clock domain, and
> transferred multi-bit data must remain coherent. Select the
> architecture yourself.

Pilot protocol: 3 circuits (`cdc_2phase`, `async_fifo`, `apbxclk`) x 2
prompts x 3 attempts. Full protocol: 44 x 2 x 3 = **264** (or x10 for
pass@10).

## 5. What JasperGold checks on each circuit

Every `benchmarks/<name>/jasper/run.tcl` does the same job with
circuit-specific clocks and resets:

```tcl
analyze ... ; elaborate -top $TOP
read_sdc $SDC_FILE
check_cdc -init
clock <clkA>
clock <clkB>
config_rtlds -reset -async {...} -polarity low
config_rtlds -port {...} -clock <clkA>
config_rtlds -port {...} -clock <clkB>
check_cdc -extract
check_cdc -list clock_signals / design_resets / declared_resets / domain_crossings
check_cdc -report -violation -detailed   ;# -> cdc_report.rpt
```

Jasper is **structural**. It does not run the testbench. It asks:

- Which clocks exist (SDC + inferred)?
- Which nets are async resets, and is deassert synchronized to the
  destination clock? (`RST_NO_SYNC`, `RST_SYNCHRONIZATION`)
- Does a flop clocked by clkA use reset from domain B? (`RDC_RS_DFRS`)
- Is there a glitch or combo on a reset path? (`RST_PH_GLCH`)
- Do multi-bit buses or binary pointers cross without a handshake / Gray
  protocol? (`DATA_*`, `CONV_*`, `HANDSHAKE_*`)
- Is a control bit sampled with fewer than two dest-clock flops? (`CDC_*`)

### Per-circuit JG setup (pilots)

**cdc_2phase** (PULP handshake)

- Clocks: `src_clk_i`, `dst_clk_i`
- Declared reset in **golden** Tcl: `common_rst_ni` (internal, async assert,
  sync deassert per domain). Ports: src group on `src_clk_i`, dst group on
  `dst_clk_i`.
- Human-repaired Tcl instead declares raw `{src_rst_ni dst_rst_ni}` so the
  injected dual-reset bug is visible.

**async_fifo** (Cummings-style)

- Clocks: `wclk`, `rclk`
- Resets: `wrst_n`, `rrst_n` (async, active-low)
- RTL files: top + `sync_r2w`, `sync_w2r`, `wptr_full`, `rptr_empty`, `fifomem`
- Ports: write side on `wclk`, read side on `rclk`

**apbxclk** (ZipCPU APB bridge)

- Clocks: `S_APB_PCLK`, `M_APB_PCLK`
- Reset: `S_PRESETn` (async). `M_PRESETn` must be a **generated**
  sync-deasserted reset on the master clock, not raw `S_PRESETn`.
- Slave APB ports on slave clock; master APB ports on master clock.

Reports written: `inferred_clocks.rpt`, `inferred_resets.rpt`,
`declared_resets.rpt`, `cdc_crossings.rpt`, `cdc_report.rpt`.

Golden reports (Torch, 13 Sep 2026, Jasper 2026.03p001): every category
**0 errors / 0 warnings** for all 44 named circuits.

## 7. Recurring CDC issue types

These types are what we encode as TB assertions. They come from original
vs fixed RTL, human-repaired files, and the one LLM that reached Jasper
(GPT-5.6).

| Type | Name | Jasper tag we saw | Typical site |
|---|---|---|---|
| **A** | Unsynchronized reset release | `RST_NO_SYNC` | Raw `wrst_n` / `src_rst_ni` into FFs |
| **B** | Foreign-domain async reset | `RDC_RS_DFRS` | `always @(posedge clkA or negedge rstB)` |
| **C** | Binary pointer CDC | `DATA_*` / `CONV_*` | `count = wptr - rptr` |
| **D** | Missing 2-flop control sync | `CDC` / `CONV` | `src_ready_o = (src_req == dst_ack)` |
| **E** | Multi-bit data without handshake | `DATA_*` / `HANDSHAKE_*` | Sample `src_data_i` on dest clock |
| **F** | Async abort used as reset | `RST_PH_GLCH` | `bus_abort` as FIFO reset |
| **G** | Combo on reset path | `RST_PH_GLCH` | `src_ready_o = src_rst_ni && ...` |
| **H** | Uncoordinated dual-domain reset | `RDC_RS_DFRS` | `src_rst_ni` and `dst_rst_ni` each raw |

**Real GPT-5.6 Jasper excerpt**
(`build/jasper/eval/.../cdc_2phase/functional/attempt-001/cdc_report.rpt`):

- `RST_PH_GLCH`: “Potential glitch in the reset path between reset
  `src_rst_ni` and data signal `src_req_toggle_q`” — because
  `src_ready_o = src_rst_ni && (src_req_toggle_q == dst_ack_sync2_q)`.
- `RDC_RS_DFRS`: flop `src_data_hold_q` (reset `src_rst_ni`) and
  `dst_data_o` (reset `dst_rst_ni`) share a data path across clocks with
  different async resets.

GPT already used 2-flop `async_reg` on req/ack. Functional TB passed.
CDC section was 0. **RDC still failed.** That is the gap the open-source
TB must catch.

### 8.3 GPT-5.6 (OpenAI, one-shot Verilog)

**Method:** same Prompt A/B as everyone. Direct Verilog. No GIR.
**Score:** 49 compile, 29 functional, 25 Jasper, **0 clean**.

**Where CDC/RDC fails (cdc_2phase attempt-001, typical):**

```verilog
assign src_ready_o = src_rst_ni && (src_req_toggle_q == dst_ack_sync2_q);
// Type G: reset used as data qualifier -> RST_PH_GLCH

always_ff @(posedge src_clk_i or negedge src_rst_ni)  // hold data
always_ff @(posedge dst_clk_i or negedge dst_rst_ni)  // dst_data_o
// Type H/B: same payload, two raw async resets -> RDC_RS_DFRS
```

2-flop sync of req/ack is present (`dst_ack_sync1_q` / `src_req_sync2_q`).
That is why **CDC** is 0 and **RDC** is not. Functional TB cannot see
reset-domain disagreement at 0-delay.

sim fails, Jasper is not run.

**apbxclk (GPT):** sim pass, `cdc=0`, `rdc=1` or `2` — same family as

### 8.6 ComplexVCoder / SysVCoder-style (Torch, 13 Sep 2026)

**Method (paper arXiv:2504.20653, later name SysVCoder):**

1. English spec (our Prompt A or B) to **GIR**.
2. GIR rewritten as a rule-alignment prompt.
3. Second stage emits Verilog.
4. Optional RAG (we set `retrieval: false`).

**What we actually ran:** paper-style reimplementation, **not** the
authors’ official repo (`official_implementation: false`).
Model: `Qwen/Qwen2.5-Coder-7B-Instruct`, NVIDIA H200, Slurm `17578034`,

**What is in GIR** (`gir.txt`, JSON):

```text
modules[]
  Top_module_name
  function          (one-line English)
  parameters[]      name + informal value
  ports[]           name, direction, width, clock_domain
  instances[]       (empty in the 27 we have)
  connections[]     (empty)
```

## 9. Assertions for a future open-source testbench

Goal: when we publish a benchmark that **cannot ship Jasper**, a normal
functional sim must **fail** the human-repaired and GPT-style RDC bugs,
and **pass** golden `fixed/rtl`.

Enable with `+define+CDC_SVA`. Bind into the DUT. Do not put these in
the generation prompt.

Positive: bind on `benchmarks/<name>/fixed/rtl` — must not fire.
Negative: bind on `experiments/human_repaired/*/generated/` — must fire
even though the old TB still prints `ALL TESTS PASSED`.

### 9.1 Properties that match errors we actually got

```systemverilog
`ifndef CDC_SVA_SV
`define CDC_SVA_SV
`define DIS(rst) disable iff (!(rst))

// Type G / RST_PH_GLCH (GPT cdc_2phase):
// ready/valid must not be a combinational AND with a raw reset pin.
property p_no_reset_in_combo_ready(clk, rst_n, ready);
  @(posedge clk) `DIS(rst_n)
    ready |-> !$isunknown(ready);
endproperty
// Structural companion (linter in TB plus):
//   forbid: assign src_ready_o = src_rst_ni && ...

// Type H / RDC_RS_DFRS (GPT + human cdc_2phase):
// if either domain reset is asserted, dest must be idle (no beat in flight).
property p_dual_rst_idle(clk, rst_a, rst_b, dest_valid);
  @(posedge clk)
    (!rst_a || !rst_b) |-> !dest_valid;
endproperty

// Type D / missing 2-flop (human cdc_2phase):
// dest-clock toggle must not be used on src clock in the same timestep.
// Proxy: src_ready_o may change only on src_clk, and not as combo of dest regs.
property p_ready_registered(clk, rst_n, ready);
  @(posedge clk) `DIS(rst_n)
    !$isunknown(ready);
endproperty
// Stronger structural check (Python on generated RTL):
//   src_ready_o\s*=\s*\(.*src_req.*dst_ack  => FAIL type D

// Type C / binary pointer (human async_fifo):
// occupancy must not be a live wptr-rptr subtract visible to both clocks.
// Proxy in TB: wfull may only change on wclk; rempty only on rclk.
property p_full_is_wclk(wclk, wrst_n, wfull);
  @(posedge wclk) `DIS(wrst_n) !$isunknown(wfull);
endproperty
// Structural:
//   wptr\s*-\s*rptr|count\s*=\s*wptr  => FAIL type C

// Type E / data hold (prompt already states this; TB should assert it):
property p_data_hold(clk, rst_n, valid, ready, data);
  @(posedge clk) `DIS(rst_n)
    (valid && !ready) |=> $stable(data) && valid;
endproperty

// Type B / foreign reset (human apbxclk):
// master-domain outputs must not async-reset when only S_PRESETn falls
// while M_PRESETn stays 1.
property p_no_slave_rst_on_mclk(mclk, s_rstn, m_rstn);
  @(posedge mclk)
    $fell(s_rstn) && m_rstn |-> 1'b0;
endproperty

// Type A / reset idle:
property p_rst_empty(rclk, rrst_n, rempty);
  @(posedge rclk) $rose(rrst_n) |-> rempty;
endproperty
property p_rst_not_full(wclk, wrst_n, wfull);
  @(posedge wclk) $rose(wrst_n) |-> !wfull;
endproperty

// ---------- binds ----------
module cdc_2phase_sva #(parameter WIDTH = 1) (
  input src_rst_ni, src_clk_i, src_valid_i, src_ready_o,
  input [WIDTH-1:0] src_data_i,
  input dst_rst_ni, dst_clk_i, dst_valid_o, dst_ready_i,
  input [WIDTH-1:0] dst_data_o
);
  a_hold: assert property (
    p_data_hold(dst_clk_i, dst_rst_ni, dst_valid_o, dst_ready_i, dst_data_o));
  a_dual: assert property (
    p_dual_rst_idle(dst_clk_i, src_rst_ni, dst_rst_ni, dst_valid_o));
  // GPT RST_PH_GLCH: ready must be a FF, not rst AND combo
  a_ready_is_ff: assert property (
    p_ready_registered(src_clk_i, src_rst_ni, src_ready_o));
endmodule

bind cdc_2phase cdc_2phase_sva #(.WIDTH(WIDTH)) u_cdc_sva (.*);

module async_fifo_sva #(parameter DSIZE = 8, ASIZE = 4) (
  input wclk, wrst_n, winc, wfull,
  input rclk, rrst_n, rinc, rempty
);
  a_rst_e: assert property (p_rst_empty(rclk, rrst_n, rempty));
  a_rst_f: assert property (p_rst_not_full(wclk, wrst_n, wfull));
endmodule

bind async_fifo async_fifo_sva #(.DSIZE(DSIZE), .ASIZE(ASIZE)) u_fifo_sva (.*);

module apbxclk_sva (
  input S_APB_PCLK, S_PRESETn, S_APB_PSEL, S_APB_PENABLE, S_APB_PREADY,
  input M_APB_PCLK, M_PRESETn
);
  a_rdc: assert property (
    p_no_slave_rst_on_mclk(M_APB_PCLK, S_PRESETn, M_PRESETn));
  a_hold_acc: assert property (
    @(posedge S_APB_PCLK) `DIS(S_PRESETn)
      (S_APB_PSEL && S_APB_PENABLE && !S_APB_PREADY)
      |=> S_APB_PSEL && S_APB_PENABLE);
endmodule

bind apbxclk apbxclk_sva u_apb_sva (.*);
`endif
```

### 9.2 Structural lint (run before sim; Xcelium will not infer this)

Jasper’s C/D/B checks are graph queries. A 20-line Python scan of
generated RTL catches the same anti-patterns we have already seen:

```python
import re
RULES = [
    (r"wptr\s*-\s*rptr|count\s*=\s*wptr", "C binary pointer CDC"),
    (r"src_ready_o\s*=\s*.*src_rst_ni\s*&&", "G reset AND into ready (RST_PH_GLCH)"),
    (r"src_ready_o\s*=\s*\(.*(?:src_req|req).*(?:dst_ack|ack)", "D combo req==ack"),
    (r"always\s*@\s*\(\s*posedge\s+(\w+)[^)]*negedge\s+(?!(?:\1))", "B foreign async reset"),
    (r"always\s*@\s*\(\s*posedge\s+dst_clk[\s\S]{0,240}src_data_i", "E sample async data"),
]
```

Fail the attempt if any rule matches. Golden `fixed/rtl` must match
**none**. Human-repaired must match **C** (fifo), **D/G** (2-phase),
**B** (apbxclk).

### 9.3 Priority (same order JG already uses to kill LLM passes)

1. **B** `RDC_RS_DFRS` — foreign reset
2. **G/F** `RST_PH_GLCH` — reset in combo / abort pulse
3. **H** uncoordinated dual reset
4. **C** binary pointers
5. **D** missing 2-flop
6. **E** data hold (already close to a functional property)

A and D need an internal tap or the lint. Port-only SVA is not enough
for Gray vs binary; that is why the lint stays in the TB flow.

## 12. How to talk about this

**Say:** Golden fixed RTL is 44/44 functional and Jasper-clean. No LLM we
scored is functional-and-CDC-clean. GPT-5.6 can pass the current TB and
still fail RDC (`RST_PH_GLCH`, `RDC_RS_DFRS`). Human-repaired files prove
the same gap on purpose. ComplexVCoder (7B+GIR) and Qwen 32B never reached
Jasper. We are designing TB assertions plus a structural lint so an
open-source benchmark can flag those CDC bugs without JasperGold.

**Do not say:** The Torch tar was LLM circuits. Human-repaired files are
model output. ComplexVCoder is official SysVCoder or Qwen 32B. Qwen 32B
was CDC-scored (it never compiled). `cdc_explicit` made models CDC-safe.
