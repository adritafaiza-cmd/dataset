Module apb_regs: An APB-mapped register file with configurable layout. Reset is active-low. Writes commit only during APB access (psel and penable). Byte strobes update only selected bytes; retain unstrobed bytes and idle-cycle state. Writable registers reset to zero. Read-only registers expose reg_init_i and ignore writes. Addresses in each AddrOffset-byte decoded range map to that register; writes outside its data width leave stored data unchanged.
