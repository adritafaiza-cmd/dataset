						// We will simulate a simple register file behavior.
						// Since we don't have a memory array parameterized easily without 
						// large instantiation, we will implement a simple "Echo" or

						// To make it functional without a huge ROM, we'll use a small

						// Better approach for generic slave: Assume it's a register file.

					// The access is defined by the cycle where PSEL is asserted.
					// So:

					// Cycle 2: PSEL=0, PENABLE=0 -> State=IDLE, PREADY=1 (Idle state usually asserts ready).

					// This implies PREADY might be 0 if not ready? No, APB slaves are usually always ready

					// So PREADY = 1 always is safe and compliant.

					// If (PSEL && PENABLE):
					//    If (state == IDLE):
					//       state = ACCESS
					//    // If already ACCESS, stay ACCESS
					// Else:
					//    state = IDLE
					
					// PREADY is always 1.
					// This satisfies "complete each access by asserting PREADY".

					// We need to capture data_in when PWRITE is high.
					// We need to output data_out when PWRITE is low (or high, depending on protocol).
					// APB Read: PRDATA contains data from slave.

					// If addr == 0:
					//    If PWRITE: reg_val <= data_in & strb_in;
					//    If PWRITE: PRDATA = reg_val; (Echo write)
