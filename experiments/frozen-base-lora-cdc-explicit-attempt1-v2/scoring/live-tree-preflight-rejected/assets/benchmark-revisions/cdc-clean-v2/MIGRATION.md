# CDC-clean benchmark migration

Version v2 is validated; see REPORT.md and VALIDATION.json. No circuit was
excluded from the 44-reference benchmark. Twenty reference implementations,
their specifications and three prompt profiles were revised. Formal contracts
and the APB enhanced strobe expectations were corrected as documented.

The original v1 working-tree files, prompts, candidates, and comparison are
unchanged. BASELINE.json records their hashes and ../cdc-clean-v1-frozen.tar.gz
archives the 994 original benchmark/support files. The version boundary is
explicit: old generated candidates/scores are not v2 results.

No new model generation, retraining, or repair feedback was performed.
