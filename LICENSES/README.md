# Upstream licensing

The benchmark contains material derived from multiple upstream projects.
Consult each upstream repository and preserve the copyright headers present in
the RTL files:

- dpretet `async_fifo`: https://github.com/dpretet/async_fifo
- ZipCPU `wb2axip`: https://github.com/ZipCPU/wb2axip
- alexforencich `verilog-axis`: https://github.com/alexforencich/verilog-axis
- PULP `common_cells`: https://github.com/pulp-platform/common_cells

The complete PULP license is available in
`vendor/common_cells/LICENSE`. Before publishing a formal benchmark release,
add verbatim license files for every vendored upstream snapshot.
